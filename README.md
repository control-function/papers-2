# Academic Central papers (2)

Past question papers and memos used by the Academic Central app (www.academiccentral.co.za).

This second repository holds every paper added from November 2026 onwards (starting with the Home Languages).
Papers added before then stay in [control-function/papers](https://github.com/control-function/papers),
which also keeps the app's paper list (manifest.json).

Department of Basic Education (DBE) papers are public documents; Academic Central practice papers are our own.
